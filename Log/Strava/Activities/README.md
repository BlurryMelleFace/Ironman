# Imported Strava Activities

Configure Strava Sync to create one activity note per workout in this folder. Map its fields to [[../../Templates/Strava Activity Template]]. Keep one note per activity so duplicate syncs can be matched by `strava_id`.

Set `week_start` to the Monday of the activity's local date and `week_number` to the corresponding week in [[../../../Plan/03 Week by Week Schedule]]. The [[../../Strava Activities.base]] view groups activities by that week start.
