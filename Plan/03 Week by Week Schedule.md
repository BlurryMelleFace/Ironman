# Week-by-Week Schedule — IRONMAN Belgium 2027

> **Thursday rule:** Every Thursday has bike intervals followed straight away by run intervals (a reduced version in recovery and taper weeks). Exceptions: Week 40 (exam) and Week 16 (easy return from leave, no intervals). The exact sets are in each week's log.

> [!IMPORTANT]
> **Leave: 24 Dec 2026 – 9 Jan 2027 (inclusive) — no training sessions.** This covers Thu–Sun of Week 13, all of Week 14, and Mon–Sat of Week 15. Training resumes on Sunday 10 Jan with an easy run; Weeks 15–16 are eased to return gently (see [[../Support/Recovery and Adjustments]]).

> Detailed session scripts for each discipline → [[../Workouts/Swim]], [[../Workouts/Bike]], [[../Workouts/Run]], [[../Workouts/Brick]], [[../Workouts/Strength]].
> Review and reassess at every 8-week benchmark test.

> [!NOTE]
> **Weeks run Monday → Sunday.** Monday is a full rest day. Strength: **legs (Tue, after the easy run)** and a short **upper body/core session (Sun)**. The long bike is Saturday; the long run is Sunday. Keep the early long run around 10–14 km and build only when recovery is good.

## Standard Week Structure (all phases)

| Day | Session | Character |
|---|---|---|
| **Mon** | 😴 **Rest day** | No planned training; optional easy mobility |
| **Tue** | 🏃 **Easy run ~7–10 km** + 💪 **Leg strength** | Run first, strength after; moderate volume |
| **Wed** | 🏊 **Swim** | Technique + endurance (volume grows by phase) |
| **Thu** | ⚡ **Bike intervals + run intervals** | Every Thursday: bike intervals, run intervals straight after (details per week in the weekly log) |
| **Fri** | 🏊 **Technique swim** + optional 🚴 **easy bike** | Easy; bike 45–60 min Z1–Z2 or skip |
| **Sat** | 🚴 **Long bike** | Z2, extend gradually; occasional short brick later |
| **Sun** | 🏃 **Long run** + 💪 **short upper body/core** | Z2, controlled; short strength with no leg load |
