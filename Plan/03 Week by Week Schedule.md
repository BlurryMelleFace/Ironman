# Week-by-Week Schedule — IRONMAN Belgium 2027

> Detailed session scripts for each discipline → [[../Workouts/Swim]], [[../Workouts/Bike]], [[../Workouts/Run]], [[../Workouts/Brick]], [[../Workouts/Strength]].
> Review and reassess at every 8-week benchmark test.

> [!NOTE]
> **Weeks run Monday → Sunday.** Monday is a full rest day. Strength: **Beine (Tue, after the easy run)** and a short **OK/Core session (Sun)**. The long bike is Saturday; the long run is Sunday. Keep the early long run around 10–14 km and build only when recovery is good.

---

## Standard Week Structure (all phases)

| Tag | Session | Charakter |
|---|---|---|
| **Mo** | 😴 **Ruhetag** | Kein geplantes Training; optional lockere Mobility |
| **Di** | 🏃 **Easy Run ~7–10 km** + 💪 **Kraft Beine** | Lauf zuerst, Kraft danach; moderates Volumen |
| **Mi** | 🏊 **Schwimmen** | Technik + Ausdauer (Umfang wächst je Phase) |
| **Do** | ⚡ **Quality Bike + kurzer Brick** | Bike-Intervalle + 10–20 min sehr lockerer Lauf (Details je Phase unten) |
| **Fr** | 🏊 **Schwimmen Technik** + optional 🚴 **Easy Bike** | Locker; Bike 45–60 min Z1–Z2 oder auslassen |
| **Sa** | 🚴 **Long Bike** | Z2, schrittweise verlängern; später gelegentlich kurzer Brick |
| **So** | 🏃 **Long Run** + 💪 **kurz Oberkörper/Core** | Z2, kontrolliert; Kraft kurz und ohne Beinbelastung |
